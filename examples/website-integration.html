🛍️ PRIMESTACK PAYMENT PROCESSOR - Website Integration

🔑 Before You Start

Get your credentials from the PRIMESTACK Merchant Dashboard (Settings tab):

  • Client ID
  • Client Secret
  • API Key

✅ Option 1: Full Payment Terminal (iFrame)

Embed the complete payment terminal directly into your website:

Code Example

<iframe 
    src="https://your-primestack-domain.com"
    width="100%"
    height="600px"
    style="border: 3px solid #e2e8f0; border-radius: 12px;"
></iframe>

✅ Option 2: Simple Checkout Button

Add a checkout button to your product pages:

Premium Subscription
$29.99/month

HTML + JavaScript Code

<button onclick="openCheckout()" style="
    background: linear-gradient(135deg, #059669, #047857);
    color: white;
    border: none;
    padding: 12px 30px;
    border-radius: 8px;
    font-size: 1rem;
    cursor: pointer;
">
    Buy Now - $29.99
</button>

<script>
function openCheckout() {
    // Open payment terminal in popup or redirect
    window.open('https://your-primestack-domain.com', '_blank', 'width=500,height=700');
}
</script>
