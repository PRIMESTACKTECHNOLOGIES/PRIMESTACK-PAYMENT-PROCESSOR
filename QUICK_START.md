# Payment Processor - Quick Start Guide

## 🚀 HOW TO USE

### **Just Double-Click: `START.bat`**

That's it! One file controls everything!

---

## 📋 MAIN MENU OPTIONS

When you open `START.bat`, you'll see:

```
================================================================================
                    PAYMENT PROCESSOR - MAIN LAUNCHER
================================================================================

 [1] Start Payment Processor Server
 [2] Open Web Interface (http://localhost:6001)
 [3] Run Unit Tests (npm test)
 [4] Run Security Tests
 [5] Run 3D Secure Educational Tests
 [6] Run ISO8583 TCP Tests
 [7] Run Merchant API Tests
 [8] Run Stripe API Tests
 [9] Run ALL Tests

 [10] Open Documentation Folder
 [11] View Transaction Logs
 [12] View Server Status

 [0] Exit
================================================================================
```

---

## 🎯 QUICK ACTIONS

### **To Start Testing:**
1. Double-click `START.bat`
2. Press `1` (Start Server)
3. Press `2` (Open Web Interface)
4. Start processing test transactions!

### **To Run All Tests:**
1. Double-click `START.bat`
2. Press `9` (Run ALL Tests)
3. Wait for results

### **To Check Security:**
1. Double-click `START.bat`
2. Press `4` (Security Tests)
3. Review results
